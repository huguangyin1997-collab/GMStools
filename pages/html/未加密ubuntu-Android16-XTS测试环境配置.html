一、Java 配置

使用APT安装Java 11

sudo apt update
sudo apt install openjdk-11-jdk

或使用下载安装方式(不推荐使用测试工具迭代后下载的固定版本会出现其他问题)

wget https://download.java.net/java/ga/jdk11/openjdk-11_linux-x64_bin.tar.gz
tar zxvf openjdk-11_linux-x64_bin.tar.gz
mv jdk-11 java-11-openjdk-amd64
sudo mv java-11-openjdk-amd64 /usr/lib/jvm

更新环境变量

编辑环境变量文件
sudo gedit ~/.bashrc
编辑环境变量文件
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64
export JRE_HOME=${JAVA_HOME}/jre
export CLASSPATH=.:${JAVA_HOME}/lib:${JRE_HOME}/lib
export PATH=${JAVA_HOME}/bin:$PATH
保存环境变量文件
source ~/.bashrc

安装多个java环境后切换需要的Java环境变量

sudo update-alternatives --config java
根据提示输入你需要的Java环境序号,回车就可以直接切换java环境
或者使用在终端导入临时环境变量的方法

编辑环境变量
sudo gedit ~/.bashrc

export ADB_HOME=/home/user/Android/Sdk/

export PATH=$ADB_HOME/tools:$PATH
刷新环境变量:
source ~/.bashrc
输入命令查看:adb devices
刷新完成后查看版本:adb --version
如果版本低于1.0.41,则adb环境没配置好,读取了默认的adb环境,读取版本时会出现一个路径,将其用rm -rf 删除，然后重启命令行终端即可。

sudo apt-get update

sudo apt-get install ca-certificates gnupg curl
1.导入 Google Cloud 公钥。
对于较新的发行版（Debian 9+ 或 Ubuntu 18.04+），请运行以下命令：
curl https://packages.cloud.google.com/apt/doc/apt-key.gpg | sudo gpg --dearmor -o /usr/share/keyrings/cloud.google.gpg

echo "deb [signed-by=/usr/share/keyrings/cloud.google.gpg] https://packages.cloud.google.com/apt cloud-sdk main" | sudo tee -a /etc/apt/sources.list.d/google-cloud-sdk.list

3.更新并安装 gcloud CLI：
sudo apt-get update && sudo apt-get install google-cloud-cli

4.运行 gcloud init 以初始化 gcloud CLI：
gcloud init
